  TIENDA DE BARRIO

Sistema de gestión para una tienda de barrio desarrollado en Java utilizando Programación Orientada a Objetos (POO) e interfaces gráficas.

DESCRIPCION

Este proyecto consiste en el desarrollo de un sistema administrativo para una tienda de barrio, permitiendo gestionar productos, ventas e inventario mediante una interfaz gráfica.
El sistema fue desarrollado aplicando conceptos de Programación Orientada a Objetos y organización por capas, separando modelo, vista y controlador.
La aplicación permite manejar información de productos, controlar ventas y almacenar datos mediante archivos.

FUNCIONALIDADES IMPLEMENTADAS

   Inicio de Sesión
Permite validar el acceso al sistema mediante una ventana de login.

 Gestión de Productos
Registro y administración de productos disponibles en la tienda.

 Registro de Ventas
Permite realizar ventas y almacenar la información correspondiente.

 Control de Inventario
Manejo y actualización del stock de productos.

Persistencia de Datos
Uso de archivos .dat para guardar información del sistema.

 Interfaz Gráfica
Ventanas gráficas desarrolladas con Java Swing para facilitar la interacción del usuario.

CONCEPTOS DE POO APLICADOS
 
 Encapsulamiento

Uso de atributos privados y métodos getters/setters para proteger la información.

 Herencia

Implementación de clases derivadas como ProductoUnidad.

 Polimorfismo

Uso de métodos reutilizables y sobrescritura de comportamientos.

 Abstracción

Separación de responsabilidades mediante paquetes de modelo, vista y controlador.
